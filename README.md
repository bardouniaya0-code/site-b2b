# Atlas Pro — Plateforme B2B

Plateforme e-commerce B2B pour les fournisseurs de l'hôtellerie-restauration.

## Lancer le projet en local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000

## Règles de l'équipe

1. On ne travaille **jamais** directement sur `main`.
2. Une branche par ticket : `feature/ATLAS-XXX-description` ou `fix/ATLAS-XXX-description`.
3. Messages de commit clairs, avec le numéro du ticket : `ATLAS-101 : nouveau slogan`.
4. Toujours `git pull` sur `main` avant de créer une branche.
5. Chaque branche passe par une **Pull Request** relue par le lead avant le merge.
